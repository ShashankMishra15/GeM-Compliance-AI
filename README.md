# GeM Compliance AI

Officer-only React prototype for AI-assisted GeM bid compliance verification.

## Run locally

```powershell
npm install
npm run dev
```

Open the local Vite URL shown in the terminal. Use the prefilled officer login to enter the demo.

## Demo highlights

- Officer-only sign-in and procurement dashboard
- New-verification document workflow with mock AI progress
- Bid compliance evidence cards, explainability actions, and consistency review
- Final decision modal requiring officer remarks (AI remains advisory)
- Risk, integrations, reports, and audit-trail screens

All government-source connections are labelled as Demo / Sandbox; this prototype makes no claim of live access.
